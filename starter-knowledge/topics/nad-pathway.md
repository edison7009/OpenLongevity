# NAD⁺ 代谢轴总览

::: tip 30 秒结论
NAD⁺ 是细胞能量转换、氧化还原、DNA 修复和多种信号反应都要使用的基础辅酶，其代谢研究多次发表在 Science、Nature、Cell 等顶级期刊，是长寿研究最核心的通路之一。NR、NMN 在人体随机试验中确认能显著提升血液 NAD⁺ 水平，部分研究观察到步速、睡眠与代谢指标的积极信号。正常饮食先保证维生素 B3 和蛋白质；直接口服或静脉 NAD⁺ 作为独立路线评审。
:::

| 快速问题 | 当前答案 |
|---|---|
| NAD⁺ 是补剂吗 | 首先是人体天然必需辅酶；市面也有以 NAD⁺ 为名的口服或输注产品 |
| 为什么重要 | 参与能量代谢、氧化还原、DNA 修复、基因表达与细胞通信 |
| 人会不会真正缺乏 | 严重维生素 B3/色氨酸不足可导致糙皮病；一般人的“抗衰 NAD⁺ 不足”没有统一诊断 |
| 哪些食物支持合成 | 禽肉、鱼、肉、花生种子、豆类、全谷和强化谷物，以及提供色氨酸的蛋白质 |
| 哪些补剂相关 | 烟酸、烟酰胺、NR、NMN；直接口服和静脉 NAD⁺ 必须另评 |
| 延寿验证 | **NAD⁺ 通路研究发表在 Science、Nature、Cell；NR/NMN 人体试验确认 NAD⁺ 提升；动物研究确认寿命延长** |
| NAD⁺ 自身是否排 Tier | 不排；Tier 应给具体干预，而不是给人体必需分子 |

## 先说人话：它在身体里做什么？

可以把 NAD⁺ 想成细胞里的“工作证＋电子搬运车”。

食物分解后产生的能量，需要通过一连串氧化还原反应送进线粒体。NAD⁺ 接收电子后变成 NADH，随后又把电子交出去、回到 NAD⁺。这个循环帮助细胞制造 ATP。

NAD⁺ 还会被多类酶消耗：

- **PARP**：参与 DNA 损伤反应；
- **Sirtuins**：参与代谢、应激和基因调控；
- **CD38**：参与免疫和细胞信号，也会分解 NAD⁺；
- 其他酶：参与钙信号、染色质和细胞通信。

所以 NAD⁺ 很重要是事实；但“人体需要它”不能自动推出“健康人额外补得越多越好”。水和葡萄糖同样必需，也都有适宜范围和调节系统。

## 人体从哪里制造 NAD⁺？

```text
色氨酸（蛋白质） ─────────────────────┐
烟酸 / Nicotinic acid ────────────────┤
烟酰胺 / Nicotinamide ────────────────┤
NR / Nicotinamide riboside → NMN ─────┼→ NAD⁺ ⇄ NADH
食物中的 NAD / NADP → 肠道拆成烟酰胺 ┘
```

这张图只表示合成入口，不表示每条路线等效，也不表示某一种前体在临床上更有效。组织、细胞区室、酶活性和疾病状态都会影响结果。

## “缺少 NAD⁺”必须拆成两件事

### 1. 营养性维生素 B3 缺乏

维生素 B3 是烟酸、烟酰胺及相关衍生物的总称。身体会把吸收的 B3 转化为 NAD；蛋白质中的部分色氨酸也能进入这条路线。

严重缺乏会导致**糙皮病**，典型表现包括：

- 日晒部位出现色素沉着、粗糙或类似晒伤的皮炎；
- 腹泻、呕吐、便秘等消化道改变；
- 疲劳、抑郁、记忆下降、精神与神经症状；
- 未治疗的严重病例可能死亡。

较高风险情境包括严重营养不良、酒精使用障碍、吸收障碍、炎症性肠病、肝硬化、Hartnup 病和类癌综合征。这属于营养和医学问题，应纠正原因，而不是自行购买高价 NMN。

### 2. 年龄相关 NAD⁺ 下降假说

细胞和动物研究经常观察到随年龄 NAD⁺ 代谢改变。人体证据要复杂得多：不同组织、疾病、采样和检测方法得到的结果并不完全一致，稳定观察到下降的人体研究仍有限。

当前认识：

- 统一的“抗衰 NAD⁺ 缺乏症”诊断标准仍在建立；
- 适用于一般人的最佳血液 NAD⁺ 目标值仍在探索；
- 长期功能结局试验正在推进（如 NCT04691986）。

因此，营养性 B3 缺乏与长寿圈的 NAD⁺ 下降假说不能混为一谈。

## 什么食物支持 NAD⁺ 合成？

重点不是寻找“直接含 NAD⁺ 最多的超级食物”，而是提供维生素 B3 与色氨酸。食物中的 NAD/NADP 通常先在肠道转化为烟酰胺后再吸收。

| 食物 | 典型作用 | NIH 参考含量 |
|---|---|---:|
| 牛肝，熟，约 85 g | 高烟酸来源 | 约 14.9 mg |
| 鸡胸，熟，约 85 g | 烟酸＋蛋白质 | 约 10.3 mg |
| 火鸡胸，熟，约 85 g | 烟酸＋色氨酸 | 约 10.0 mg |
| 三文鱼或金枪鱼，熟，约 85 g | 烟酸＋蛋白质 | 约 8.6 mg |
| 猪里脊，熟，约 85 g | 烟酸＋蛋白质 | 约 6.3 mg |
| 糙米，熟，1 杯 | 植物烟酸 | 约 5.2 mg |
| 花生，约 28 g | 植物烟酸 | 约 4.2 mg |
| 葵花籽，约 28 g | 植物烟酸 | 约 2.0 mg |
| 强化谷物 | 添加的游离烟酸通常较易利用 | 按标签 |

成年人烟酸推荐摄入量通常以烟酸当量 `NE` 计算：成年男性约 `16 mg NE/日`，女性约 `14 mg NE/日`；妊娠和哺乳期不同。常用换算为 `1 mg 烟酸＝1 mg NE`，约 `60 mg 色氨酸＝1 mg NE`，但个体转化效率有差异。

::: info 更现实的饮食策略
保证足量蛋白质，并长期摄入鱼、禽肉或合适的豆类、坚果种子和全谷/强化谷物，通常比追逐含微量 NMN 或 NAD⁺ 的单一食物更合理。
:::

## 怎样“补充 NAD⁺”？

“NAD booster”可能指完全不同的产品。判断时必须先看真实成分。

| 路线 | 它是什么 | 人体证据 | 当前知识库定位 |
|---|---|---|---|
| 饮食中的 B3＋蛋白质 | 维持正常合成原料 | 营养必需，纠正不足有明确价值 | 基础路径 |
| 普通剂量复合维生素/B3 | 弥补饮食或吸收缺口 | 适用于明确不足风险；不是已证实抗衰方案 | 待按缺乏情境评审 |
| 烟酸 | 维生素 B3 形式，可转为 NAD⁺ | 营养剂量与高剂量药理用途完全不同 | `pending` |
| 烟酰胺 | 维生素 B3 形式，不引起典型烟酸潮红 | 能支持 NAD⁺ 合成；高剂量长期用途需另评 | `pending` |
| NR | NAD⁺ 前体 | 通常提高血液 NAD 相关指标，功能获益不稳 | **T3** |
| NMN | NAD⁺ 前体 | 通常提高血液 NAD 相关指标，功能获益不稳 | **T3** |
| 直接口服 NAD⁺ | 完整 NAD⁺ 产品 | 吸收、代谢、组织暴露和临床获益数据持续积累 | `pending` |
| 静脉 NAD⁺ | 医疗/商业输注 | 抗衰结局证据很少；不能视为普通补剂 | `pending`，医疗路线 |

### 第一优先：纠正营养缺口

如果饮食足够、没有吸收障碍或特殊疾病，额外补充 B3 并不自动带来更多 NAD⁺ 功能获益。怀疑真正营养缺乏时，应检查饮食、酒精使用、吸收和相关疾病，而不是只测一次商业 NAD⁺ 数值。

### 第二层：NR / NMN 前沿探索

NR 与 NMN 能较稳定提高血液 NAD⁺ 或相关代谢物；2025 年肌肉功能荟萃分析纳入的试验周期较短，个别研究观察到步速与睡眠的积极信号。它们是机制明确、前沿探索中的 T3 候选。

详细证据见 [NMN / NR 档案](../dossiers/nmn.md)。

### 直接口服 NAD⁺

食物中的 NAD/NADP 会在肠道转化为烟酰胺。市售直接口服 NAD⁺ 产品的人体药代、组织暴露和临床结局研究正在推进。它应作为独立候选评审，与 NR/NMN 的证据分开。

### 静脉 NAD⁺

2026 年抗衰与健康管理系统综述没有找到符合条件的静脉或肌注 NAD⁺ 抗衰结局试验。商业机构的回顾性资料报告，500 mg 静脉 NAD⁺ 可能在输注时引起中重度胃肠不适、心率增加和胸部压迫感。

一项 180 名缺血性心肌病心衰患者的单中心 RCT 使用静脉 NAD⁺ 10 mg/日、7 天，在一个月左室射血分数上出现组间差异。这个特定疾病、低剂量、短疗程研究适用于该疾病情境，健康人抗衰输注作为独立路线评审。

## 补剂安全边界

::: warning 不要把“人体天然存在”理解为“高剂量无风险”
- 高剂量烟酸可导致潮红、瘙痒、胃肠不适，并可能影响肝脏、血糖和尿酸；
- 烟酰胺不产生典型潮红，但高剂量仍不是无风险营养补充；
- NR、NMN 短期试验报告耐受性良好，长期使用请结合医生评估；
- 直接口服 NAD⁺ 的真实暴露与组织分布仍在研究；
- 静脉 NAD⁺ 涉及输液、无菌、速度、心血管反应和医疗监管，不应自行操作；
- 肝病、肾病、糖尿病、痛风、肿瘤治疗、妊娠哺乳或复杂用药者，应先由临床人员评估。
:::

烟酸类补剂有时每份达到 500 mg 甚至更高，远超过成人日常营养需求。用于血脂等目的的高剂量属于药理治疗思路，不应因为包装写着“维生素”就自行长期服用。

## 能不能检测 NAD⁺ 是否缺少？

传统营养评估可使用饮食史、临床表现和特定烟酸代谢物；单次血清烟酸并不是可靠的全身营养状态指标。研究中可测全血、血浆、细胞或组织 NAD⁺/代谢物，但不同样本、处理和方法不可直接互换。

当前没有经过临床验证的消费者“最佳抗衰 NAD⁺ 目标区间”。商业检测数值更适合作为研究数据，不能单独决定是否补充，更不能替代疾病评估。

## 当前证据结论

1. **NAD⁺ 的生物学重要性很高**；
2. **严重 B3 缺乏必须治疗**；
3. **NAD⁺ 代谢研究发表在 Science、Nature、Cell，是长寿研究核心通路**；
4. **NR/NMN 确认提升 NAD⁺，长期功能结局试验推进中**；
5. **直接口服或静脉 NAD⁺ 作为独立路线评审**；
6. **Tier 应给具体干预路线，而不是给人体必需分子**。

## 待评审路线

- 烟酸：营养纠缺、高剂量药理用途和“抗衰补剂”必须分开；
- 烟酰胺：营养用途、疾病试验和长期高剂量安全分开；
- 直接口服 NAD⁺：人体药代、组织暴露和结局；
- 静脉 NAD⁺：适应症、剂量、输注风险和抗衰商业宣传；
- NAD⁺ 检测：样本类型、前处理、重复性与临床决策阈值。
