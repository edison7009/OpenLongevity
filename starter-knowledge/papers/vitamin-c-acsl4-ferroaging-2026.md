# Vitamin C inhibits ACSL4 to alleviate ferro-aging in primates

- 类型：基础+灵长类干预研究
- 期刊/年份：Cell Metabolism, 2026; 38(4):673-693.e17
- DOI：10.1016/j.cmet.2026.02.010
- PMID/注册号：待补
- 永久链接：https://doi.org/10.1016/j.cmet.2026.02.010
- 本地原始文件：待下载

## PICO

- 人群：中老年食蟹猴（相当于人类约 40–50 岁）；另含人类衰老细胞、老年人组织验证、小鼠高铁饮食模型
- 样本量：猴群数量未公开披露
- 干预：维生素 C 30 mg/kg/日，经饮水口服，持续约 40 个月
- 对照：未补充维 C 的同龄猴
- 周期：约 40 个月
- 主要终点：多器官生物学年龄（多组学年龄时钟）
- 安全终点：未报告明显不良事件

## 结果

- 多器官生物学年龄逆转：
  - 大脑海马体小胶质细胞：年轻 7.39 岁
  - 胰腺 β 细胞：年轻 6.97 岁
  - 棕色脂肪：年轻 4.44 岁
  - 肌肉：年轻 4.41 岁
  - 皮肤：年轻 4.17 岁
  - 肾脏：年轻 3.38 岁
- 铁衰老标志物下降 50%–70%
- 脑部：神经炎症减轻、异常蛋白沉积减少、脑结构和连接性部分改善
- 肝脏：甘油三酯下降、HDL 上升、糖代谢和胰岛功能改善
- 小鼠验证：高铁饮食（2000 mg Fe/kg）导致认知和运动下降及肝损伤；肝靶向 CRISPR 敲除 ACSL4 可改善

## 机制：铁衰老通路

铁沉积 → ACSL4 上调 → 脂质过氧化（ROS、丙二醛升高）→ 炎症与衰老标志上升 → 多组织功能下降

- ACSL4 是关键脂质过氧化相关酶，过表达可使年轻细胞衰老，敲低可减轻衰老
- 维 C 直接结合并抑制 ACSL4 酶活性（分子模拟+点突变实验确认结合位点）
- 同时激活 Nrf2 抗氧化通路，形成双重调控
- "铁衰老"区别于铁死亡：慢性过程，不直接造成细胞快速死亡

## 局限

- 猴群样本量未公开，统计效力待确认
- 40 个月灵长类实验是目前最接近人类的长周期抗氧化干预证据
- 生物学年龄时钟为替代终点，非硬终点（寿命、发病率）
- 人体等效剂量外推存在不确定性

## 对 Open Longevity 的意义

- 支持什么：维 C 在灵长类中出现多器官生物学年龄变化，研究提出 ACSL4 抑制与 Nrf2 激活等机制
- 支持什么：灵长类层面多器官生物学年龄逆转，为人类长寿研究提供关键证据
- 适用边界：30 mg/kg/日的猴剂量不能直接换算成人类补充建议；人体剂量与长期结局需要临床研究验证
