# 科学证据怎么看

::: tip 核心原则
机制可以解释“为什么可能有用”，人体临床结局才能回答“对谁真正有用”。某位名人使用、某项指标上升，都不能单独确定效果。
:::

## 优先级

1. 临床指南、系统综述与高质量荟萃分析；
2. 多个独立随机对照试验；
3. 单个随机试验与前瞻性观察研究；
4. 动物、细胞、机制与专家假说。

研究类型不能代替研究质量。低质量荟萃分析不会自动成为高等级证据。

## Open Longevity Tier

| Tier | 含义 | 常见情况 |
|---|---|---|
| T1 | 高优先级基础策略 | 适用面广、人体功能或临床结局较稳定 |
| T2 | 特定情境有较明确价值 | 需要目标、检测、剂量边界或特定人群 |
| T3 | 有条件地考虑 | 短期指标多于长期功能结局 |
| T4 | 早期人体探索 | 样本小、周期短或复方试验居多 |
| T5 | 前沿或高度不确定 | 机制、动物或个案为主，不应作为常规方案 |

Tier 是研究和决策优先级，不是剂量建议，也不是“必买榜”。

## 阅读一个结论时的 6 个问题

1. 研究的是人、动物还是细胞？
2. 改善的是疾病、功能，还是一个替代指标？
3. 结果是组间差异，还是只有组内变化？
4. 效应有多大，绝对差异是多少？
5. 是否适用于我的年龄、健康状态和目标？
6. 资金、产品和研究团队之间是否有利益关系？
