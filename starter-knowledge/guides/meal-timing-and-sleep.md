# 晚间进食与睡眠

::: tip 实用结论
多数人不需要模仿某位名人的极端进食窗口。如果大餐会引起反流、胃胀、夜间血糖波动或睡眠不适，可尝试在睡前 2–3 小时结束大餐，再用自己的睡眠和症状记录调整。
:::

## 已知与不确定

- 胰岛素敏感性和葡萄糖耐量具有昼夜节律，晚间处理同等热量的能力可能较差；
- 晚间大餐对反流、消化不适和一部分人的睡眠有实际影响；
- 限时进食的效果受总热量、饮食质量、时间窗口和人群影响；
- 不能根据短时空腹直接推断人体“自噬已启动”或已经获得延寿效果。

## 怎么做

1. 先保持一日总摄入和蛋白质充足；
2. 连续 2 周记录最后一餐时间、餐量、反流、入睡时间和夜醒；
3. 若无明显问题，没必要追求超长的睡前空腹窗口；
4. 糖尿病、易低血糖、妊娠或有进食障碍史时，不要自行采用极端限时进食。
