# 补剂产品怎么选

::: tip 品牌名不能代替产品检查
同一品牌可能同时销售不同剂量、原料、化学形式和认证状态的产品。判级对象应该是“品牌 + 完整产品名 + 市场版本 + 批次”。
:::

## 两条不同的轴

| 轴线 | 回答的问题 |
|---|---|
| 证据 Tier（T1–T5） | 这种干预对什么人、什么结局有多少人体证据？ |
| 产品 Tier（P1–P3） | 这一款具体产品是否准确、纯净、新鲜、可追溯？ |

P1 产品不会让 T5 干预变成 T1；T1 干预也不代表任何同名产品都值得买。

## 产品检查顺序

1. 核对完整产品名、SKU、国家版本和标签日期；
2. 看每份实际活性成分、化学形式及单方/复方；
3. 优先可在认证机构数据库核对的具体产品；
4. 其次是带批号、实验室、日期、方法和结果的 COA；
5. 查看该品类特有风险，如鱼油氧化、重金属和运输温度；
6. 最后再看价格、口味和包装。

GMP 说明生产体系，不等于手中这瓶产品的含量、污染物和新鲜度已经公开验证。

## P1–P3

| 档次 | 标准 |
|---|---|
| P1 | 具体产品身份、剂量透明，并有可独立核对的产品级认证或较完整批次报告 |
| P2 | 产品和剂量清楚，但当前批次、类别特有检测或独立核对存在缺口 |
| P3 | 主要依赖厂商声明，可核对的产品级资料较少 |

没有产品符合 P1 时就让 P1 空缺。价格高、品牌大或名人使用都不是升档理由。
