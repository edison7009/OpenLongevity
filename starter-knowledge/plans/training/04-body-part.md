# 胸背腿肩臂（4 分化）

| 项目 | 建议 |
|---|---|
| 适合谁 | 以肌肥大为主、喜欢单次专注少数部位的经验训练者 |
| 频率 | 每周 4 次；弱项可用少量附加组增加第二次刺激 |
| 时长 | 约 60–80 分钟/次 |
| 优点 | 局部训练时间充足，容易安排辅助动作 |

::: warning 四分化不等于更高级
若经常漏掉某一天，该部位可能整周都没训到。对大多数健康目标用户，全身或上下肢通常更容易长期执行。
:::

## 四日模板

| 训练日 | 主要动作 | 建议量 |
|---|---|---|
| 胸 + 三头 | 卧推、上斜推、夹胸、三头下压 | 复合 3 组，辅助 2–3 组 |
| 背 + 二头 | 引体或下拉、划船、后束、二头弯举 | 复合 3 组，辅助 2–3 组 |
| 腿 | 深蹲或腿举、罗马尼亚硬拉、分腿蹲、腿弯举、小腿 | 每项 2–3 组 |
| 肩 + 手臂 | 上方推、侧平举、后束、二头、三头 | 每项 2–3 组 |

## 每周安排

- 例：周一胸，周二背，周四腿，周六肩臂。
- 单次某部位的有效组数不要一开始就堆得很高；先从 6–10 组/周开始观察恢复。
- 若主要目标是延寿与功能，仍应保留负重携带、核心稳定和每周有氧训练。
