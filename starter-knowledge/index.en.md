# Open Longevity Knowledge Base

A local-first, source-traceable document library for longevity research.

This is not a "must-buy list." Every item must distinguish between public-figure protocols, human evidence, conditions of applicability, safety boundaries, and unresolved questions.

## Core Principles

1. "Bryan uses it" does not mean "the general public should use it."
2. New candidates default to `pending`.
3. A mechanistic or biomarker change is not equivalent to a healthspan benefit.
4. Conclusions must state limitations and safety boundaries together.
5. New content enters the knowledge base before it enters any web interface.
