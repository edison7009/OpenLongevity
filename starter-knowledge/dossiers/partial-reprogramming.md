# 部分细胞重编程（山中因子）

部分细胞重编程试图短暂启动 OCT4、SOX2、KLF4 等重编程因子，让细胞的部分年龄相关状态向年轻方向移动，同时避免把成熟细胞完全重置成多能干细胞。它的潜力很高，但目前仍属于不可自行实践的前沿生物技术。

| 快速判断 | 当前答案 |
|---|---|
| 它是什么 | 暂时、受控地表达 OSK 或 OSKM 等重编程因子 |
| 与 iPSC 的区别 | iPSC 是完全重编程；部分重编程希望保留原有细胞身份 |
| 当前进展 | 动物研究出现组织修复与延寿信号；人体研究刚进入局部、早期安全性探索 |
| 主要风险 | 细胞身份丢失、异常增殖、肿瘤风险以及递送和剂量控制 |
| 当前等级 | **T5：前沿探索** |

## Bryan Johnson 做了什么？

Bryan Johnson 在 2026 年公开表示，他将自己血液来源的细胞用山中因子重编程为诱导多能干细胞（iPSC），并把它描述为“新生的自己”。科学上这不是人体克隆，也没有让他的身体直接年轻化；得到的是培养皿中与他遗传背景相同的多能干细胞。

这些细胞理论上可以继续分化为神经、心肌或视网膜等细胞，用于疾病建模、药物测试和未来的自体细胞治疗。完整器官替换和全身年轻化仍是远景，不是已经实现的临床结果。

## 老年小鼠的 OSK 实验

一项预印本研究向 124 周龄的正常老年小鼠递送可诱导的 OSK。研究报告：

- 对照组从干预开始计算的中位剩余寿命为 8.86 周；
- OSK 组为 18.5 周，因此“剩余寿命”增加 109%；
- 从出生计算的中位总寿命约由 133 周提高至 142.5 周，并不是总寿命翻倍。

该实验使用 AAV9 递送基因表达系统，属于基因治疗式递送，不是使用 CRISPR 改写小鼠基因组。结果仍需独立重复和更大规模验证。

## 不要与早衰症基因编辑混为一谈

另一项研究使用 CRISPR 衍生的腺嘌呤碱基编辑器，修复早衰症小鼠的 `LMNA` 致病突变，使其中位寿命由 215 天提高至 510 天。这是针对严重单基因疾病的病因治疗，不能直接解释为正常小鼠或正常人的通用延寿方案。

## 为什么暂列 T5？

- 生物学潜力可能远高于多数补剂；
- 正常衰老动物已经出现值得继续研究的信号；
- 人体有效性、长期安全性、递送方式与可逆控制尚未解决；
- 当前没有面向普通人的可执行方案，也不应通过未经监管的细胞或基因治疗机构尝试。
