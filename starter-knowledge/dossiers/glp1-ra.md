# GLP-1 受体激动剂

::: tip 30 秒结论
GLP-1 是人体肠道天然分泌的饱腹激素。GLP-1 受体激动剂是模拟这个激素的处方药，最初用于糖尿病，现在广泛用于减重。Bryan Johnson 2026 年 7 月公开将其纳入延寿平台，定位为"可能的延寿药"。**这是处方药，不是补剂，需要医生评估和处方。**
:::

| 快速判断 | 当前答案 |
|---|---|
| 它是什么 | 模拟肠道 GLP-1 激素的处方药，降低食欲、延缓胃排空、刺激胰岛素 |
| 为什么延寿圈关注 | 减重之外，研究显示降压、调糖、降脂、抗炎、可能降低心血管事件风险 |
| Bryan Johnson 怎么用 | 2026-07 将 6 款 GLP-1 药物加入 immortals.com 平台，定位为减重 + 延寿 |
| 处方还是补剂 | **处方药**，必须医生评估后使用 |
| 当前等级 | **T2：大规模人体获益数据（减重、心血管）已确认；延寿终点仍在观察** |

- 品牌药：Zepbound®（替尔泊肽 KwikPen）、Wegovy®（司美格鲁肽注射）、Wegovy®（口服）、Foundayo®（口服）；
- 复合处方：个性化 Tirzepatide 注射、个性化 Semaglutide 注射；

- 定位：不只是减重，是"可能的延寿药"。

## 先说人话：它在身体里做什么？

吃完饭后，肠道 L 细胞释放 GLP-1 激素，它做三件事：

1. **告诉大脑"饱了"**——作用于下丘脑食欲中枢，降低进食欲望和"food noise"；
2. **减慢胃排空**——食物在胃里停留更久，饱腹感延长；
3. **刺激胰岛素、抑制胰高血糖素**——降低餐后血糖峰值。

GLP-1 受体激动剂就是把这个天然信号放大、延长。天然 GLP-1 半衰期只有 1–2 分钟（被 DPP-4 酶迅速降解），药物版本经过改造可以持续数天。

## 为什么延寿圈关注它？

### 已确认的人体获益

| 终点 | 证据 |
|---|---|
| 减重 15–25%（68–72 周） | SELECT、STEP、SURMOUNT 系列 RCT |
| 降低主要心血管事件（MACE）20% | SELECT 试验（司美格鲁肽 2.4 mg，超重 + 心血管病史） |
| 降低 HbA1c、改善胰岛素抵抗 | 多项糖尿病 RCT |
| 降低收缩压 ~5 mmHg | 多项 RCT 汇总 |
| 降低甘油三酯、LDL、炎症标志物（CRP） | 多项 RCT |

### 正在研究的延寿相关方向

- 肾脏保护（FLOW 试验：司美格鲁肽降低糖尿病肾病进展）；
- 神经保护 / 认知（阿尔茨海默病在研）；
- 成瘾行为（酒精、尼古丁、购物冲动——观察性信号）；
- 抗炎与免疫调节；
- 直接寿命延长——动物数据支持；大型观察性研究显示司美格鲁肽使用者全因死亡率显著更低，人体延寿终点正在多项在研试验中验证。

## 谁适合考虑？

::: tip 适用场景
- BMI ≥ 30（肥胖），或 BMI ≥ 27 + 至少一项合并症（高血压、高血脂、2 型糖尿病前期）；
- 有明确代谢综合征表现；
- 长期"food noise"严重、靠意志力无法控制进食量；
- 在医生指导下使用，定期复查。
:::

::: warning 不适合自行使用的情况
- BMI 正常、只是想"抗衰"——风险收益比不支持；
- 有甲状腺髓样癌个人或家族史（动物实验中有 C 细胞肿瘤信号）；
- 有胰腺炎病史；
- 妊娠、哺乳、计划怀孕；
- 1 型糖尿病或糖尿病酮症酸中毒；
- 严重胃肠疾病（胃轻瘫等）。
:::

## 常见副作用

- **最常见**：恶心、呕吐、腹泻、便秘（通常前 4–8 周明显，逐渐减轻）；
- 注射部位反应；
- 少见但严重：胰腺炎、胆囊疾病、肠梗阻；
- 快速减重可能伴随肌肉流失——需配合力量训练和充足蛋白质。

## 与项目其他策略的关系

- **不是补剂**，不能和 NMN、亚精胺、肌酸等放在同一个"每日补剂栈"里讨论；
- 如果正在医生指导下使用 GLP-1，饮食结构通常也需要相应调整，并关注蛋白质摄入、胃肠耐受和总能量；
- 减重期间力量训练更重要，防止肌肉流失；
- Bryan Johnson 将其定位为"延寿平台的一个工具"，不是"人人该打的针"。
