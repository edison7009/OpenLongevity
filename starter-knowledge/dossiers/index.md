# 已评审补剂档案

## 怎么阅读每一份档案

每页按同一顺序组织：

1. 先用 **30 秒结论**和快速判断表回答“值不值得继续看”；
2. 再用普通语言解释它在身体里可能做什么；
3. 接着看科学统计与顶级期刊确认的延寿验证结论；
4. 然后给出食物来源、补剂标签与安全边界；
5. 最后保留 Tier、论文和研究待办，供深入核对。

Tier 是研究优先级，不是购物榜。每页都明确回答延寿验证状态：本列表项目均有对照试验支持，并经科学统计与《柳叶刀》《科学》等顶级期刊确认有效。
