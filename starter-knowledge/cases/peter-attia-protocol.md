# Peter Attia 的方案

Peter Attia，长寿医学医生、前外科医生，《Outlive: The Science and Art of Longevity》作者、The Drive 播客主理人。他的定位是**把医学从"治病"转向"防病 + 延长健康寿命"**，方案以运动为第一杠杆、以可测量指标驱动，补剂态度相对克制。

::: tip 阅读方式
本页记录 Attia 的公开框架与做法，用于发现值得进一步研究的策略，不等于 Open Longevity 对剂量、处方或品牌的推荐。尚未逐条归档一手来源的内容标为 `needs-source-check`；与 Thorne 的合作关系单独披露。
:::

## 核心理念

- **Medicine 3.0**：从"得病后治疗"（2.0）转向"个性化预防 + 以功能/健康寿命为中心"。
- **四大骑士（four horsemen）**：动脉粥样硬化病、癌症、神经退行性疾病、代谢病——80% 以上 50 岁后非吸烟死亡归于此四类，方案围绕推迟/逆转它们。
- **百年十项全能（centenarian decathlon）**：倒推"100 岁还想能做的 10 件事"，反推现在要练什么、留多少余量（margin of safety）。
- **五大策略（five tactics）**：运动、睡眠、营养、外源分子（药/补剂/激素）、**情绪与压力耐受（distress tolerance）**——他特别强调第五条常被忽略，情绪健康是独立支柱（与冲绳的 moai/ikigai 同向）。
- **补剂三段框架**：① 目标是什么 ② 有没有可追踪的生物标志物 ③ 风险是否值得——不盲补。

## 补剂协议（克制派，先测后补）

| 补剂 | 其公开常见做法 | 说明 |
|---|---|---|
| Omega-3 | 重 EPA/DHA，盯 **Omega-3 index** 这个指标来调剂量 | 不只看"吃没吃"，看血里够不够 |
| 维生素 D3 | **先测** 25(OH)D，公开内容常讨论约 40–60 ng/mL 与 K2 | 这是人物方案记录，不是通用目标或剂量建议 |
| 镁 | 甘氨酸镁 / 苏糖酸镁，睡前 | 助睡眠与恢复 |
| 肌酸 | 公开内容常讨论约 5 g/天，并覆盖女性与老年人 | 应结合对应策略档案和个人健康状况理解 |
| B12 / 甲基化相关 | 按需，结合检测 | |

## 训练（他认为的第一杠杆，"没有之一"）

四类能力全覆盖，对应百年十项全能：

| 类型 | 其公开常见安排 | 强度/说明 |
|---|---|---|
| Zone 2 有氧 | 每周累计 ~3–4 小时 | 能说话但不能唱歌的强度，练线粒体 |
| VO2max | 每周 1 次 **4×4 协议** | 4 分钟接近最大 + 4 分钟恢复 ×4，练心肺天花板 |
| 力量 | 每周 3–4 次 | 重握力、离心、关节全幅度，留余量防伤 |
| 稳定性/平衡 | 每天 | 他称为"运动中的运动"，防跌倒/受伤 |

## 营养

- **蛋白质优先**：约 1.6–2.2 g/kg/天（按瘦体重可更高），分餐、每餐踩亮氨酸阈值；公开澄清"高蛋白致癌"是误解。
- 不教条：按个人代谢反应调整，不绑死某饮食流派。
- **盯 ApoB/血脂**：他标志性、较激进的观点——主张用药物（他汀/PCSK9 等）把 ApoB 压到极低，视其为动脉粥样硬化的因果因子。**这是处方层，不可自行仿照。**
- 控制精制糖、精制碳水、酒精。

## 睡眠与情绪

- 固定作息、卧室降温、避光；与睡眠专家 Matthew Walker 做过 7 集系列，视睡眠为核心修复工具。
- **酒精**：公开认为几乎无安全量、严重伤睡眠与健康，他自己基本不喝。
- 情绪/压力耐受作为第五支柱，主动训练而非"顺其自然"。

## 一天大致节奏（公开内容归纳，非逐分钟官方日程）

```
晨起   光照 + 水 + 电解质
上午   训练（力量 / Zone2 / VO2max / 稳定性 轮换）+ 高蛋白早餐
白天   补剂随餐（D3+K2、Omega-3、肌酸等，按检测定制）
傍晚   收尾工作，避强光
睡前   镁，降温避光，固定时间入睡；不饮酒
```
